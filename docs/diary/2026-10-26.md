## What we did

Six gates passed and pushed: G02, G05, G06, G07, G08, plus the human approvals that make G06 and G08 real. Nemotron did not happen; everything else did, and more.

**G02, contracts.** Pydantic schemas with `extra='forbid'` for every persisted object, the adapter interface, SHA-256 manifests, 35 tests. The schemas refuse a PASS carrying a violation, an ELIGIBLE release without all three suites green, and a classical controller described as GR00T.

**G05, the simulator loop.** Separate venv, Menagerie Panda pinned at `f3b6013` (Apache-2.0, recorded). A staged, hashed push scene: floor, 4 cm block, target disk, fingertip site. A classical 6-DoF damped-least-squares IK push controller, `push-dls-ik-v1`. Four perturbations that provably change the model or the observation: start offset, mass, friction, observation delay. Bit-identical replay. Nine videos. Two bugs found only by running: gravity sag swallowed the IK increment until the commanded joint position became controller state, and position-only IK let the hand tilt into the floor until orientation was held.

**G06, the oracle.** A pure function of trajectory, spec and target. Precedence INVALID, SAFETY_FAIL, TASK_FAIL or TIMEOUT, PASS. Six injected faults plus a simulated infrastructure failure all came out INVALID, TIMEOUT or EXEC_ERROR, never PASS. Adam reviewed and approved the push TestSpec v1: 4 cm radius, 25 stable steps, 15 s deadline, collisions forbidden, no force limit claimed. Verdicts on the G05 runs: 8 PASS, and the two 200 ms delay episodes are SAFETY_FAIL, fingers on the floor.

**G07, protocol and baseline.** Everything a search strategy will be judged against is locked and hashed: domain with published weights, seed partition, five reserved held-out configurations, budgets 3/25/25, metrics named before running. Three nominal runs, byte-identical. Random baseline, 25 unrendered episodes at 0.56 s each: 22 PASS, 3 SAFETY_FAIL, all with delay at or above 152 ms. First failure at episode 16, nearest at distance 0.885. That is the bar G10 must beat.

The baseline took three attempts, and the reason matters. The first run reported six failures; three were "block reached the target and left it". The runner cut recordings half a second after the goal, while the block was still sliding and, once, while the arm was climbing back to re-push. Verdicts depended on where the cut fell. Now every episode is recorded for the full 15 s deadline. The three artefact failures recovered. Recorded so nobody rediscovers it as a finding.

**G08, Tavily evidence chain.** One live search, request id recorded, five results including Franka's datasheet. A regex pulled `Payload 3 kg` into a PROPOSED constraint; Adam reviewed the matched text and approved. The domain check reported "consistent" against our 0.5 kg cap and changed nothing: the code path never mutates bounds. A hypothesis, labelled human-authored because Nemotron is pending, tied to the constraint; its corner scenario, 0.5 kg at 200 ms delay, ran and the oracle said SAFETY_FAIL.

**Rules and habits added.** Adam set a test discipline rule, now spec section 12.2: no redundant tests, combine checks that share a scene or episode, render video only for what will be shown. Honoured today: oracle tests are one builder and one parametrised table, sweeps run unrendered, one video per gate.

**Secrets.** Getting the Tavily key onto disk took four tries through editors; a PowerShell script with hidden input solved it. The first live call failed on a stray carriage return, and the SDK's error echoed the auth header into one evidence file, scrubbed and deleted before any commit. The loader now strips the key, errors are redacted, and every run scans the evidence folder for the key pattern.

**Tooling lessons**, both now in memory: Python one-liners run from Windows write CRLF, which breaks WSL shell scripts, and the Bash tool halves backslashes in heredocs.
